This is an experimental, noncommercial visual demo. Signing accuracy has not been validated by a fluent Deaf signer. Word playback follows input order and is not sentence translation.

  • three.ws: procedural signing modules from commit 20b1bd378da0e12c107737c5e1828b0807c50644. Local modification: corrected scalar facial keyframe packing when joining clips. Copyright 2026 nirholas. Apache 2.0; notice.
  • Three.js 0.184.0: local WebGL rendering. MIT license.
  • Reference character: sourced from three.ws public/avatars/cz.glb at the pinned engine commit. It is used because the procedural motion was authored on this exact skeleton, avoiding the hand and arm distortion introduced by cross-character retargeting. The repository distributes it under its Apache 2.0 project license; commercial asset provenance should still be checked independently before shipping.

Text is processed entirely in this browser. No camera, accounts, cloud model, or analytics are used.
